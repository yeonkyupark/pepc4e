## 3.4.1 표준과 표준화 {#t34-1}

### 표준과 표준화의 관계 (109회)

- **표준(Standard)**: 관계자들이 이익과 편의를 공정하게 얻도록 통일·단순화를 목적으로 물체·성능·절차·방법 등에 대해 정한 **결정(규정)**
- **표준화(Standardization)**: 표준을 **설정하고, 보급·활용하며, 개정하는 조직적 행위(과정)**

표준은 표준화의 **결과물**이고, 표준화는 표준을 만들고 지키고 고쳐 나가는 **순환 과정**이다(설정 → 실시 → 평가 → 개정).

### 공적 표준과 사실상 표준

| 구분 | 공적 표준(De jure) | 사실상 표준(De facto) |
|---|---|---|
| 정의 | 공인된 표준화 기관이 **공개적 합의 절차**를 거쳐 제정한 표준 | 공식 절차 없이 **시장 경쟁에서 지배적 지위**를 얻어 표준이 된 것 |
| 제정 주체 | ISO, IEC, ITU, 국가표준기관(KS) | 특정 기업·기업군 |
| 특징 | 중립성·공개성·합의성, 제정에 시간이 걸림, 권고 또는 법적 강제 | 빠른 형성, 네트워크 효과, 특정 기업의 이익·독점 우려 |
| 예 | ISO 9001, KS 규격, 미터법 | PC 운영체제, QWERTY 자판 |

(그 중간 형태로, 여러 기업이 모여 만드는 **포럼·컨소시엄 표준**도 있다.)

### 표준의 특성

① **통일성·단순성**: 다양성을 줄여 하나로 맞춤 ② **반복성**: 반복적으로 쓰이는 대상에 적용 ③ **합의성**: 이해관계자의 합의로 제정 ④ **객관성·공정성** ⑤ **개방성**: 누구나 이용 가능 ⑥ **동태성(시한성)**: 기술 변화에 따라 정기적으로 개정

### 표준화의 원리 (ISO/STACO)

ISO 표준화원리위원회(STACO)가 정리한 표준화의 일곱 가지 원리(T.R.B. Sanders)

1. 표준화는 본질적으로 **단순화**의 행위이며, 사회의 의식적인 노력의 결과다.
2. 표준화는 경제적·사회적 활동이므로 **관계자 모두의 상호 협력(합의)**으로 추진해야 한다.
3. 표준은 출판만으로는 가치가 없으며 **실시되어야** 한다.
4. 표준을 정할 때는 **선택하고 일정 기간 고정**하는 일이 필요하다.
5. 표준은 일정 기간마다 **검토하고 필요하면 개정**해야 한다.
6. 제품 성능 등을 규정할 때는 **시험·평가 방법**도 함께 규정해야 한다.
7. 국가 표준을 **법으로 강제할지**는 표준의 성격, 산업화 수준, 법률 체계 등을 고려해 신중히 결정해야 한다.

### 표준화의 생산상 효과

| 영역 | 효과 |
|---|---|
| 설계 | 부품 재사용·공용화로 설계 기간 단축 |
| 생산 | 호환성 부품으로 대량생산·자동화 용이, 준비교체 감소, 작업 숙련도 향상 |
| 자재·재고 | 품목 수 감소, 재고·관리비 절감, 대량 구매로 단가 인하 |
| 품질 | 품질의 균일화·안정, 검사 기준 명확 |
| 원가·납기 | 원가 절감, 리드타임 단축 |

### 사내표준화의 역효과

- **경직성**: 표준이 창의성과 개선을 막을 수 있음
- **다양성 감소**: 고객의 개별 요구에 대한 대응력 약화
- **형식화**: 문서만 있고 현장에서 지켜지지 않음
- **진부화**: 개정되지 않은 표준이 기술 발전을 저해
- **관리 부담**: 과잉 표준으로 제정·유지 비용 증가

→ 대책: 현장 참여형 제정, 정기 검토·개정, 필요 최소한의 표준, 표준 준수와 개선의 선순환(표준 → 개선 → 재표준화)

!!! tip "답안 작성 포인트"
    - 109회는 소문항이 6개다. 각각을 **번호 그대로 소제목**으로 두고 표·목록으로 짧게 채운다.
    - STACO 원리는 7개 항목을 핵심어(단순화·협력·실시·선택과 고정·개정·시험방법·법적 강제)로 외운다.

## 3.4.2 5S·3정 {#t34-2}

### 5S의 개념 (130회)

| 단계 | 일본어 | 의미 | 주요 활동 |
|---|---|---|---|
| **정리**(Sort) | 整理 Seiri | 필요한 것과 불필요한 것을 구분해 **불필요한 것을 없앰** | 빨간 딱지(Red Tag) 작전, 불용품 처분 기준 |
| **정돈**(Set in order) | 整頓 Seiton | 필요한 것을 **누구나 바로 꺼내 쓸 수 있게** 위치를 정하고 표시 | 3정(정품·정량·정위치), 형적 정리(공구 모양 표시판), 위치 표시 |
| **청소**(Shine) | 清掃 Seiso | 쓰레기·더러움을 없애고 **청소하면서 점검** | 청소 구역·책임자 지정, 청소 점검 기준, 발생원 대책 |
| **청결**(Standardize) | 清潔 Seiketsu | 정리·정돈·청소 상태를 **표준화해 유지** | 5S 기준서, 체크리스트, 눈으로 보는 관리 |
| **습관화**(Sustain) | 躾 Shitsuke | 정해진 규칙을 **스스로 지키는 습관** | 교육, 순회 점검·평가, 경진대회, 경영층 솔선 |

**6S (88회)**: 5S에 **안전(Safety)**을 더한 것이다. 동기생산(JIT) 도입 시 현장의 기본 질서를 세우고 안전을 함께 확보하기 위해 적용한다. (교재에 따라 안전 대신 다른 항목을 더하기도 하므로, 답안에는 어떤 6가지인지 명확히 밝힌다.)

### 3정(定) (130회)

**정돈 단계의 실천 수단**으로, 물건을 다음 세 가지로 정한다.

| 3정 | 의미 | 예 |
|---|---|---|
| **정품**(定品) | 정해진 물품 | 품목명·품번 표시 |
| **정량**(定量) | 정해진 수량 | 최대·최소 재고 표시선 |
| **정위치**(定位置) | 정해진 장소 | 바닥 구획선, 선반 번지, 주소 표시 |

### 5S 활동의 필요성

1. **낭비 제거**: 물건 찾기·운반·대기 시간 감소
2. **품질 안정**: 이물·혼입·오조립 방지
3. **설비 고장 예방**: 청소가 곧 점검 — 이상(누유·풀림)의 조기 발견
4. **안전 확보**: 통로 확보, 걸림·넘어짐 사고 예방
5. **개선 활동의 기반**: TPM·JIT·6시그마 등 모든 혁신 활동의 출발점
6. 작업 의욕과 기업 이미지(고객 방문 시 신뢰) 향상

### 5S 추진 단계

① 경영층 선언과 추진 조직 구성 → ② 교육과 현황 사진 기록(Before) → ③ 정리(빨간 딱지 작전) → ④ 정돈(3정, 표시) → ⑤ 청소·점검 → ⑥ 청결(기준서·체크리스트) → ⑦ 습관화(정기 점검·평가·포상) → ⑧ 개선 결과 비교(After)와 확산

!!! tip "답안 작성 포인트"
    - 5S는 **단계별 의미 + 주요 활동 표**를 쓰고, 3정은 정돈의 수단이라는 관계를 분명히 한다.
    - 필요성은 품질·원가·납기·안전·설비의 관점으로 나누면 빠짐없이 쓸 수 있다.

??? example "관련 기출 2문항 (88회, 130회)"

    - **제88회(2009) 1교시 6번** · 10점  
      동기 생산 시스템 도입시 적용하는 6S를 설명하시오.
    - **제130회(2023) 3교시 2번** · 25점  
      3정(定)과 5S의 개념을 각각 설명하고, 5S활동의 필요성 및 주요활동 내용에 대하여 설명하시오.

## 3.4.3 눈으로 보는 관리 {#t34-3}

### 눈으로 보는 관리의 개념 (71회)

**눈으로 보는 관리(Visual Management)**는 현장의 상태와 **정상·이상 여부를 누구나 한눈에 알 수 있도록 시각화**해, 이상을 즉시 발견하고 조치하게 하는 관리 방식이다.

**원칙**: ① 한눈에 보인다 ② 누구나 같은 판단을 할 수 있다 ③ 정상 기준이 표시되어 있다 ④ 이상을 보면 즉시 조치할 수 있다

### 대표적인 예

| 대상 | 예 |
|---|---|
| 생산·진도 | 시간대별 계획 대비 실적 관리판, 안돈(라인 이상 표시등), 간판 |
| 품질 | 불량 현황판, 불량품 견본 진열, 한도 견본, 검사 합격 표시 |
| 설비 | 계기의 정상 범위 색상 표시, 볼트 맞춤 표시(풀림 확인), 오일 레벨선, 급유·점검 표시 |
| 자재·재고 | 최대·최소 재고선, 3정(품목·수량·위치) 표시, 선입선출 표시 |
| 작업·인력 | 표준작업표 게시, 다기능 스킬 맵, 출근·배치 현황판 |
| 환경·안전 | 바닥 구획선·통로 색상, 위험 구역 표시, 형적 정리판 |
| 경영 지표 | KPI 대시보드(OEE·불량률·납기준수율), 전자 현황판 |

### 기대효과

1. **이상의 조기 발견과 신속한 조치** — 문제가 커지기 전에 대응
2. **숙련 의존도 감소** — 누구나 같은 기준으로 판단
3. **의사소통 향상** — 목표·현황을 모두가 공유
4. **낭비 감소** — 찾기·확인·문의 시간 단축
5. **개선 동기 부여** — 목표 대비 실적이 보이면 자발적 개선 촉진
6. **관리·감독 부담 감소**와 **안전 향상**

!!! tip "답안 작성 포인트"
    - **정의 → 원칙 → 대상별 예시 표 → 기대효과** 순으로 쓴다. 예시는 생산·품질·설비·자재·안전 영역별로 고르게 든다.
    - 최근에는 MES·IoT 기반 **전자 현황판·디지털 대시보드**로 발전하고 있다는 점을 결론에 덧붙인다.

??? example "관련 기출 1문항 (71회)"

    - **제71회(2003) 4교시 2번** · 25점
