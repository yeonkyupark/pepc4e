    5.1.1 작업측정과 표준시간¶

    개요: 작업측정과 시간연구의 목적 (109회)¶

    작업측정(Work Measurement)은 숙련된 작업자가 정해진 방법으로 작업을 수행하는 데 필요한 시간을 설정하는 기법이다(ILO). 테일러의 시간연구(1880년대)와 길브레스의 동작연구에서 출발했으며, 방법연구(무엇을 어떻게 할 것인가)와 짝을 이뤄 작업연구(Work Study)를 구성한다.

    시간연구의 목적 내용
    표준시간 설정 계획·원가·평가의 공통 기준
    비효율 발견 유휴·대기·비부가가치 시간의 정량화 → 개선 대상 선정
    작업 방법 비교 개선 전후·대안 방법의 시간 비교
    계획·통제 기초 생산능력·인원·설비 산정, 라인밸런싱, 일정계획
    공정한 평가·보상 능률 측정과 성과급의 근거

    표준시간의 정의 (63·127·136회)¶

    표준시간(Standard Time)은 정해진 작업 조건과 방법에 따라, 그 작업에 알맞은 숙련도를 가진 작업자가 정상적인 속도로 작업할 때 1단위의 작업을 끝내는 데 필요한 시간이다.

    \[ \text{표준시간} = \text{정미시간} + \text{여유시간}, \qquad \text{정미시간} = \text{관측 평균시간} \times \text{레이팅 계수} \]
    flowchart LR
    O["관측시간<br/>(평균)"] -->|"× 레이팅 계수"| N["정미시간<br/>(Normal Time)"]
    N -->|"+ 여유시간<br/>(일반·특수여유)"| S["표준시간<br/>(Standard Time)"]

    표준시간 측정의 작업 조건 7가지 (127회): ① 작업 방법 ② 설비·치공구 ③ 재료(자재) ④ 작업 환경(조명·온도·소음) ⑤ 작업자의 숙련도·적성 ⑥ 작업 속도(정상 페이스) ⑦ 품질 기준

    구비 조건 (127회): ① 정확성: 객관적이고 과학적으로 측정 ② 공정성: 작업자와 관리자 모두 납득 ③ 달성 가능성: 정상적인 작업자가 무리 없이 달성(일관성·재현성 포함)

    활용 용도 (136회): 생산계획·일정계획, 필요 인원·설비 산정, 라인밸런싱, 원가 계산·견적, 작업 능률 평가와 성과급, 작업 개선 효과 측정

    방법 내용 장점 단점
    경험견적법 숙련자의 경험으로 추정 빠르고 비용 없음 주관적, 정확도 낮음
    실적자료법 과거 작업 실적의 평균 자료가 있으면 간편 비효율이 그대로 반영됨
    스톱워치법 직접 관측 후 레이팅·여유 반영 정확, 반복 작업에 적합 레이팅의 주관성, 관측 부담
    워크샘플링 무작위 순간 관측으로 비율 추정 비반복·다수 작업자에 적합, 관측 부담 적음 짧은 반복 작업 상세 분석에 부적합
    PTS법 기본 동작별 미리 정한 시간을 합산 레이팅 불필요, 작업 전 설정 가능 분석에 숙련·시간 필요, 기계 시간 제외
    (표준자료법) 요소별 표준 자료를 조합 유사 작업에 신속 적용 자료 구축 비용

    스톱워치법 절차: 작업 표준화 → 요소작업 분할 → 관측 횟수 결정 → 관측 → 이상치 제거·평균 → 레이팅 → 여유 부가 → 표준시간

    필요 관측 횟수 (73회)¶

    신뢰도 95%, 상대 정도 ±5%일 때

    \[ N' = \left( \frac{40\sqrt{N\sum X^2 - (\sum X)^2}}{\sum X} \right)^2 \]

    풀이: \( N = 10,\ \sum X = 66,\ \sum X^2 = 446 \)

    \[ N\sum X^2 - (\sum X)^2 = 4{,}460 - 4{,}356 = 104, \qquad N' = \left( \frac{40 \times \sqrt{104}}{66} \right)^2 = (6.18)^2 = 38.2 \rightarrow \mathbf{39\text{회}} \]

    → 필요 관측 횟수(39회)가 실제 관측(10회)보다 많으므로 29회를 더 관측하고, 전체 자료로 다시 \( N' \)을 계산해 충분한지 확인한다.

    내경법과 외경법 (121회)¶

    구분 외경법 내경법
    여유율 \( A = \dfrac{\text{여유시간}}{\text{정미시간}} \) \( A = \dfrac{\text{여유시간}}{\text{실동시간}(=\text{정미}+\text{여유})} \)
    표준시간 \( ST = NT \times (1 + A) \) \( ST = \dfrac{NT}{1 - A} \)

    풀이: 평균 = 26.09 ÷ 10 = 2.609분, 정미시간 = 2.609 × 0.85 = 2.218분

    • 외경법: \( 2.218 \times 1.25 = \mathbf{2.77\text{분}} \)
    • 내경법: \( 2.218 \div (1 - 0.25) = \mathbf{2.96\text{분}} \)

    피치타임 흐름작업에서 제품 1개가 나오는 계획 시간 간격

    정미시간 정상 속도로 작업할 때 순수하게 필요한 시간(관측시간 × 레이팅)
    여유시간 작업 중 불규칙하게 생기는 피할 수 없는 지연을 보상하는 시간
    표준시간 정미시간 + 여유시간

    PAC 시스템 (85회)¶

    PAC(Performance Analysis & Control)는 표준시간을 기준으로 작업 능률을 측정·분석·통제하는 능률관리 시스템이다.

    • 특징: 전체 능률을 작업자 책임인 작업 능률과 관리자 책임인 가동률(관리 효율)로 나눠 측정 → 능률 저하의 책임 소재를 명확히 함
    • 종합 능률 = 작업 능률(표준시간 합계 ÷ 실제 작업시간) × 가동률(실제 작업시간 ÷ 근무시간)
    • 효율적 능률관리의 요건: 정확한 표준시간, 실적 데이터의 정확한 수집, 책임 구분과 피드백, 공정한 평가와 보상, 관리자 교육

    표준시간 관리의 실무 이슈와 최근 동향¶

    구분 내용

    5.1.2 여유시간과 여유율¶

    여유시간의 종류 (68·73·115·130회)¶

    여유시간은 정미시간 외에 작업 중 불규칙적으로 발생하는 피할 수 없는 지연과 피로를 보상하는 시간이다.

    구분 종류 내용
    일반여유 작업여유 공구 교환·청소·급유 등 작업 중 불규칙하게 생기는 작업
    직장여유 작업 지시·자재 대기 등 직장 관리상 피할 수 없는 지연
    용달여유(인적여유) 물 마시기·화장실 등 생리적 욕구
    피로여유 작업에 따른 피로 회복
    특수여유 기계간섭여유 다기계 담당 시 여러 기계가 동시에 정지해 생기는 대기
    조(組)여유 여러 명이 조를 이뤄 작업할 때 작업 불균형에 따른 대기
    소로트여유 로트가 작아 작업에 익숙해지기 전에 끝나서 생기는 손실
    장사이클여유 사이클이 길어 작업 리듬을 타기 어려워 생기는 손실
    관리여유(관리계수) 관리가 충분하지 못해 생기는 손실을 일시적으로 보정하는 여유 — 관리 개선에 따라 줄여 나가야 함

    여유율 (130회)¶

    \[ \text{외경법: } A = \frac{\text{여유시간}}{\text{정미시간}}, \qquad \text{내경법: } A = \frac{\text{여유시간}}{\text{정미시간} + \text{여유시간}} \]

    여유율은 워크샘플링이나 연속 관측으로 조사하고, 일반적으로 사내 규정으로 정한다. 같은 여유시간이라도 내경법의 여유율이 외경법보다 작게 나온다.

    내경법과 외경법의 관계: 외경 여유율 \( A_o \)와 내경 여유율 \( A_i \)는 \( A_o = \dfrac{A_i}{1 - A_i} \)의 관계다(예: \( A_i = 20\% \)이면 \( A_o = 25\% \)). 외경법은 정미시간에 곱하므로 계산이 간편하고, 내경법은 근무시간 중 여유의 비중을 직관적으로 보여 준다.

    여유율 결정 방법

    방법 내용
    워크샘플링 일정 기간 무작위 관측으로 여유 항목별 발생 비율 추정 — 가장 많이 사용
    연속 관측(전일 관측) 하루 전체를 연속 관측해 여유 발생 시간을 직접 측정
    여유율표(ILO 등) 인적여유·기본 피로여유에 작업 자세·중량·조명·소음·정신 긴장 등 가산 요인을 더해 산정(교재 확인 필요)
    사내 규정·노사 합의 위 결과를 바탕으로 작업 유형별 표준 여유율 확정

    피로여유에 영향을 주는 요인: 작업 강도(중량·자세), 작업 환경(온도·소음·조명), 정신적 긴장·단조로움, 작업 시간대(야간) — 인간공학적 작업 개선으로 피로 자체를 줄이는 것이 근본 대책이다.

    답안 작성 포인트

    • 여유는 일반여유 / 특수여유의 분류표가 핵심이다. 특수여유의 관리여유(관리계수)는 "관리 개선으로 줄여야 할 여유"라는 성격을 강조한다.
    • 여유율은 내경법·외경법 식을 함께 쓰고 차이를 설명한다. 결정 방법(워크샘플링·여유율표)까지 쓰면 차별화된다.
    • 결론 예: "여유율은 한 번 정하면 고정되기 쉬우므로, 관리여유는 관리 개선 목표와 연동해 줄이고 피로여유는 인간공학적 개선으로 축소해 표준시간의 경쟁력을 높여야 한다."
    관련 기출 5문항 (68회, 73회, 97회, 115회, 130회)

    5.1.3 레이팅(수행도 평가)¶

    레이팅의 필요성 (70회)¶

    레이팅(Rating, 수행도 평가)은 관측 대상 작업자의 작업 속도를 정상 속도와 비교해 평가하는 것이다. 관측된 작업자가 정상보다 빠르거나 느리면 관측 시간을 그대로 쓸 수 없으므로, 레이팅 계수로 정상 속도 기준의 정미시간으로 보정한다.

    \[ \text{정미시간} = \text{관측 평균시간} \times \frac{\text{레이팅 계수}(\%)}{100} \]

    레이팅 기법 (70·71·91회)¶

    기법 내용
    속도 평가법 작업 속도만을 정상 속도(100%)와 비교해 평가 — 가장 널리 사용
    웨스팅하우스법(평준화법) 숙련·노력·작업조건·일관성의 4가지를 평가해 합산
    객관적 평가법 속도만 평가한 뒤 작업 난이도(신체 사용·페달·양손·눈과 손의 협응·취급 주의·중량)를 2차로 보정(Mundel)
    합성 평가법 PTS로 구한 시간과 실측 시간의 비로 레이팅 계수를 산출(Morrow)
    노력 평가법·페이스 평가법 작업자의 노력 정도·작업 페이스를 평가

    레이팅 훈련이 안 된 경우 (91회): 관측자의 주관이 개입되지 않는 합성 평가법을 쓴다.

    \[ \text{레이팅 계수} = \frac{\text{PTS로 구한 시간}}{\text{실측 평균 시간}} \]

    몇 개 요소작업을 PTS로 분석해 계수를 구하고, 나머지 요소에도 같은 계수를 적용한다.

    웨스팅하우스법의 평가 항목 (127회)¶

    ① 숙련(Skill) ② 노력(Effort) ③ 작업 조건(Conditions) ④ 일관성(Consistency) — 각 항목을 등급별 평가값으로 정하고

    \[ \text{레이팅 계수} = 1 + (\text{숙련} + \text{노력} + \text{조건} + \text{일관성의 평가값 합}) \]

    웨스팅하우스사의 Lowry·Maynard·Stegemerten이 개발한 평준화법(Leveling)으로, 대표적인 평가값은 다음과 같다(등급 세분은 교재마다 다를 수 있다).

    항목 최상(A) 우수(B) 양호(C) 보통(D) 미흡(E) 불량(F)
    숙련 +0.15 ~ +0.13 +0.11 ~ +0.08 +0.06 ~ +0.03 0 −0.05 ~ −0.10 −0.16 ~ −0.22
    노력 +0.13 ~ +0.12 +0.10 ~ +0.08 +0.05 ~ +0.02 0 −0.04 ~ −0.08 −0.12 ~ −0.17
    작업 조건 +0.06 +0.04 +0.02 0 −0.03 −0.07
    일관성 +0.04 +0.03 +0.01 0 −0.02 −0.04

    예: 숙련 C1(+0.06), 노력 B2(+0.08), 조건 D(0), 일관성 C(+0.01) → 레이팅 계수 = 1 + 0.15 = 1.15

    레이팅의 정확도 향상¶

    • 관측자 훈련: 표준 속도(예: 카드 52장 배분 0.5분, 평지 보행 시속 약 4.8km 등 교재의 정상 속도 기준)를 담은 레이팅 영상으로 반복 훈련
    • 복수 관측자 평균, 관측 대상은 보통 수준 작업자 선정
    • 객관화 보완: 합성 평가법(PTS 기준)으로 주관 검증, 최근에는 영상 분석으로 동작 속도를 정량화

    답안 작성 포인트

    • 필요성(정상 속도로 보정) → 공식 → 기법 비교표가 기본 틀이다. 91회처럼 훈련 부족 상황을 물으면 합성 평가법과 그 식을 쓴다.
    • 웨스팅하우스법은 4항목 + 평가값 표 + 계산 예를 쓰면 10점 문제에서도 차별화된다.
    • 결론 예: "레이팅은 표준시간 오차의 최대 원천이므로, 관측자 정기 훈련과 PTS 기반 합성 평가로 주관성을 줄여 노사가 신뢰하는 표준을 만들어야 한다."

    5.1.4 워크샘플링¶

    워크샘플링의 정의와 특징 (82·109·139회)¶

    워크샘플링(Work Sampling)은 관측 대상(작업자·설비)을 무작위 시점에 순간적으로 관측해 작업·비작업 상태의 비율을 통계적으로 추정하는 작업측정 기법이다(L. H. C. Tippett, 1934).

    주요 특징 (139회)

    1. 순간 관측: 연속 관측 대신 무작위 순간에 상태만 기록
    2. 통계적 추정: 관측 비율로 전체 시간 비율을 추정(이항분포), 관측 수로 정도 조절
    3. 관측 부담이 적음: 한 명이 여러 작업자·설비를 동시에 관측, 작업자의 의식 영향이 적음
    장점 단점
    관측자 1명이 여러 대상 관측, 비용 적음 짧은 반복 작업의 상세 분석에 부적합
    비반복·장시간 작업에도 적용 작업 방법 개선 정보는 얻기 어려움
    작업자의 부담·저항이 적음 무작위성이 깨지면 편향 발생
    관측 중단·재개가 자유로움 개별 작업자의 차이를 알기 어려움

    절차와 관측 횟수 (73·109회)¶

    ① 목적 설정 → ② 관측 대상·항목(작업·비작업 분류) 정의 → ③ 예비 관측으로 비율 \( p \) 추정 → ④ 필요 관측 수 결정 → ⑤ 무작위 관측 시각 결정 → ⑥ 관측·기록 → ⑦ 결과 분석·관리도로 안정성 확인 → ⑧ 개선

    \[ \text{절대 정도 } e: \ N = \frac{Z^2\, p(1-p)}{e^2}, \qquad \text{상대 정도 } s: \ N = \frac{Z^2 (1-p)}{s^2\, p} \qquad (95\% \text{에서 } Z \approx 2) \]

    가동률 향상 방안 (73회): 비가동 요인(대기·고장·자재 부족·준비)을 항목별로 집계해 파레토 분석 → 큰 항목부터 대책(자재 공급 개선, 예방보전, 준비교체 단축, 작업 지시 개선)

    관측 결과의 안정성 확인 (109회): 일자별 작업 비율 \( p_i \)를 p 관리도로 그려 관리한계를 벗어난 날은 원인을 조사한다.

    \[ UCL,\ LCL = \bar p \pm 3\sqrt{\frac{\bar p(1 - \bar p)}{n}} \qquad (n: \text{일일 관측 수}) \]

    무작위 관측 시각의 결정: 난수표·난수 발생기로 시각을 정한다. 일정 간격으로 관측하는 계통 샘플링은 작업 주기와 겹치면 편향이 생기므로 주의한다.

    워크샘플링과 스톱워치법의 비교 (109회)¶

    구분 워크샘플링 스톱워치 시간연구
    관측 방식 무작위 순간 관측(상태 기록) 연속 관측(시간 측정)
    이론 근거 확률·이항분포 직접 측정 + 레이팅
    적합 대상 비반복·장주기 작업, 다수 작업자·설비, 가동률 분석 짧은 주기의 반복 작업
    관측자 부담 적음(1인이 다수 관측) 큼(1인 1대상)
    작업자 저항 적음 큼(측정 의식)
    산출물 가동률·여유율·작업 구성비 요소작업별 정미시간

    가동분석 활용 사례¶

    • 설비 가동분석: 가동·정지(고장·준비·대기) 비율 → OEE의 시간가동률 검증(3.5.3)
    • 간접 인력 분석: 사무·보전·물류 인원의 업무 구성비 → 적정 인원 산정
    • 최근 동향: IoT 센서·PLC 신호로 설비 상태를 전수·연속 수집하는 방식이 확산되어, 워크샘플링은 사람 중심 업무(간접·서비스)와 데이터가 없는 영역에 주로 쓴다.

    워크샘플링에 의한 표준시간 (63·100회)¶

    \[ \text{단위당 정미시간} = \frac{\text{총 작업시간} \times \text{작업 비율} \times \text{평균 수행도}}{\text{생산량}}, \qquad \text{표준시간} = \text{정미시간} \times (1 + \text{여유율}) \]

    풀이: 63회

    \[ \text{정미시간} = \frac{460 \times 0.85 \times 1.10}{300} = 1.434\text{분}, \qquad \text{표준시간} = 1.434 \times 1.10 = \mathbf{1.58\text{분/개}} \]

    (여유율을 내경법으로 적용하면 \( 1.434 \div 0.9 = 1.59 \)분)

    답안 작성 포인트

    • 표준시간 계산은 공식에 각 항목의 출처(타임카드·워크샘플링·사내규정)를 대응시켜 설명한다.
    • 109회 "가동분석"형 문제는 스톱워치법과의 비교표 + p 관리도에 의한 안정성 확인을 넣으면 차별화된다.
    • 결론 예: "워크샘플링은 적은 비용으로 가동 손실을 드러내는 도구이므로, IoT 설비 데이터와 병행해 사람 중심 업무의 비가동 요인을 찾아 개선하는 데 활용해야 한다."

    5.1.5 PTS법(MTM·WF·RWF·MODAPTS)¶

    PTS법의 개념¶

    PTS(Predetermined Time Standards, 기정시간표준)법은 작업을 기본 동작으로 분해하고, 각 동작에 미리 정해진 표준 시간값을 합산해 정미시간을 구하는 방법이다. 레이팅이 필요 없고, 작업을 시작하기 전(설계 단계)에도 시간을 정할 수 있다.

    장점 단점
    레이팅이 불필요해 객관적·일관적 기본 동작 분해에 숙련된 분석자와 시간 필요
    생산 전(설계·공정 계획 단계)에 표준시간 설정 기계 가공시간·정신 작업·비반복 작업에는 부적합
    동작 단위 분석으로 방법 개선점이 함께 드러남 짧은 주기의 수작업 중심, 기법별 라이선스·교육 비용
    작업자를 직접 관측하지 않아 저항이 적음 여유는 별도로 부가해야 함

    주요 PTS 기법 비교

    기법 개발 시간 단위 특징
    MTM-1 Maynard 등(1948) 1 TMU = 0.036초 가장 정밀, 분석 시간이 큼
    WF Quick 등(1930~40년대, 교재 확인 필요) 1 WFU = 0.0001분 동작 곤란도(Work Factor)로 시간 가산
    RWF WF 간략화 1 RU = 0.001분(교재 확인 필요) 현장 적용 속도 개선
    MODAPTS Heyde(1966, 호주) 1 MOD = 0.129초 신체 부위별 정수 배수, 배우기 쉬움
    MOST Zandin(1970년대, 메이너드사) TMU(지수 × 10) 동작 순서 모델(일반 이동·제어 이동·공구 사용)로 분석 속도가 빠름

    MTM(Method Time Measurement) (73·88·91회)¶

    1948년 미국 웨스팅하우스사의 Maynard 등이 개발했다. 시간 단위는 1 TMU = 0.00001시간 = 0.036초이다.

    기본 동작 (88회) — 손·팔 8가지 + 눈 2가지 + 신체 동작 1군 = 11가지

    구분 동작
    손·팔 동작 손뻗기(R), 운반(M), 회전(T), 누르기(AP), 쥐기(G), 정치(위치 맞추기, P), 놓기(RL), 떼어 놓기(D)
    눈 동작 눈의 이동(ET), 눈의 초점 맞추기(EF)
    신체 동작 발·다리 동작, 보행, 굽히기·앉기·서기 등

    표준시간 설정 4단계: ① 작업을 MTM 기본 동작으로 분해 ② 동작별 변수(거리·케이스·중량) 결정 ③ MTM 표에서 TMU 값을 찾아 합산 → 정미시간 ④ 여유를 더해 표준시간 산정

    동작 유형 Type Ⅰ·Ⅱ·Ⅲ (91회): 손뻗기·운반 동작의 시작과 끝 상태에 따른 구분

    유형 내용 시간
    Type Ⅰ 동작의 시작과 끝 모두 정지 상태(가속·감속 모두 있음) 가장 김
    Type Ⅱ 시작 또는 끝 한쪽이 움직이는 상태(가속·감속 중 하나만) 중간
    Type Ⅲ 시작과 끝 모두 움직이는 상태(가속·감속 없음) 가장 짧음

    동작 연합 (73회): 둘 이상의 동작이 동시에 일어나면, 시간이 긴 제한 동작(Limiting Motion)의 시간만 계산한다.

    연합 형태 예 계산
    결합 동작(한 신체 부위가 두 동작 동시) 손을 뻗으면서 손목 회전: R20B + T60 10.0 vs 4.1 → 10.0 TMU
    결합 동작 물건을 옮기며 회전: M30B + T60 13.3 vs 4.1 → 13.3 TMU
    동시 동작(서로 다른 신체 부위) 오른손 R20B와 왼손 M20B를 동시에 10.0 vs 10.5 → 10.5 TMU

    (쥐기 G2 = 5.6 TMU처럼 다른 동작과 겹칠 수 없는 동작은 따로 더한다. 동시 동작의 가능 여부는 동작 난이도에 따라 MTM 동시동작표로 판단한다.)

    WF(Work Factor)법 (71·127회)¶

    시간 단위는 1 WFU = 0.0001분이다.

    • 표준 요소 8가지: 이동(손뻗기·운반), 쥐기, 미리 놓기, 조립, 사용, 분해, 내려놓기, 정신 과정
    • 시간을 결정하는 변수 4가지: ① 사용 신체 부위 ② 이동 거리 ③ 중량·저항 ④ 동작 곤란도(Work Factor)
    • 표준시간 설정 절차: 작업 분해 → 요소별 변수 결정 → WF 시간표에서 값 합산 → 정미시간 → 여유 부가

    RWF(Ready Work Factor)법 (68·103회)¶

    WF법을 간략화해 현장에서 빠르게 적용할 수 있게 만든 방법이다.

    이동(R·M) 동작 규칙에 영향을 주는 3가지 요소: ① 사용 신체 부위(손가락·팔·앞팔 회전·몸통·발 등) ② 이동 거리 ③ 동작 곤란도(중량·저항 포함)

    동작 곤란도 척도 5가지 (103회)

    기호 곤란도 예
    W 중량·저항(Weight) 무거운 물건 운반, 뻑뻑한 레버 당기기
    D 일정한 정지(Definite stop) 정해진 위치에서 정확히 멈춤(스위치 위치)
    S 방향 조절(Steering) 좁은 구멍으로 핀을 안내
    P 주의(Precaution) 깨지기 쉬운 물건·액체가 든 컵 운반
    U 방향 변경(Change direction) 장애물을 피해 돌아가는 동작

    MODAPTS (127회)¶

    MODAPTS(Modular Arrangement of PTS)는 동작을 신체 부위의 이동 단위로 표시하는 간편 PTS로, 시간 단위는 1 MOD = 0.129초다. 신체 동작은 다음 3가지로 나눈다.

    1. 이동 동작(Movement): 손가락(M1)·손(M2)·앞팔(M3)·팔 전체(M4)·어깨까지 뻗기(M5) 등
    2. 종결 동작(Terminal): 잡기(Get: G0·G1·G3), 놓기(Put: P0·P2·P5)
    3. 신체·보조 동작: 보행(W5), 굽히기(B17), 앉고 서기(S30), 발 페달(F3), 읽기·판단 등

    답안 작성 포인트

    • PTS 문제는 시간 단위(TMU·WFU·MOD)를 반드시 쓰고, 기본 동작·변수를 표로 정리한다.
    • MTM 동작 연합은 "긴 동작의 시간만 계산"이라는 원칙과 주어진 TMU 값으로 예를 든다.
    • 25점 문제는 PTS 기법 비교표 + 장단점을 덧붙여 전체 체계를 아는 것을 보여 준다.

    적합 대상 주기가 비교적 긴 작업, 일반 개선 주기가 매우 짧은 반복 작업, 고숙련 동작

    5.1.7 학습곡선¶

    학습곡선(Learning Curve)의 개념 (70·85·88·112회)¶

    같은 작업을 반복하면 작업자의 숙련으로 단위당 작업시간이 줄어든다. 누적 생산량이 2배가 될 때마다 단위당 시간이 일정 비율(학습률)로 줄어든다는 것이 학습곡선이다(1936년 T. P. Wright, 항공기 생산).

    \[ Y_x = a\, x^{-b}, \qquad b = -\frac{\log r}{\log 2} \]

    (\( Y_x \): x번째 단위의 소요시간, \( a \): 첫 단위 소요시간, \( r \): 학습률, \( b \): 학습 지수)

    LCF(Learning Curve Factor): 학습률 \( r \)에 따라 x번째 단위의 시간이 첫 단위의 몇 배인지 나타내는 계수 \( x^{-b} \) — 표로 만들어 공수 예측에 쓴다.

    풀이: 109회 (첫 단위 10시간, 학습률 80%)¶

    \( b = -\log 0.8 / \log 2 = 0.322 \)

    누적 생산 대수 1 2 4 8 16 32
    해당 대수의 공수(시간) 10.0 8.0 6.4 5.12 4.10 3.28

    → 누적 생산량이 2배가 될 때마다 공수가 20%씩 줄어든다. 초기에는 감소 폭이 크고, 생산이 누적될수록 완만해진다.

    LCF 계산 예 (88회): 학습률 80%에서 10번째 단위의 LCF \( = 10^{-0.322} = 0.476 \) → 10번째 단위 공수 = 첫 단위 공수 × 0.476

    두 가지 학습곡선 모형

    모형 \( Y_x \)의 의미 비고
    누적평균시간 모형(Wright) 1~x번째 단위의 누적 평균 시간 Wright(1936)의 원래 모형, 견적·총공수 예측에 편리
    단위시간 모형(Crawford) x번째 단위 하나의 시간 위 풀이처럼 개별 단위 공수 예측에 사용

    같은 학습률이라도 두 모형의 결과가 다르므로, 답안에서는 어느 모형인지 밝힌다.

    5.1.8 과학적 관리법¶

    테일러의 과학적 관리법 (121회)¶

    F. W. Taylor(1911, 『과학적 관리의 원칙』)는 주먹구구식 관리 대신 과학적 방법으로 하루의 공정한 작업량(과업)을 정해 관리하는 과업관리를 제창했다.

    4대 원칙

    1. 작업의 각 요소를 과학적으로 연구해 주먹구구식 방법을 대체
    2. 작업자를 과학적으로 선발·훈련
    3. 과학적 원리에 따라 작업이 이루어지도록 관리자와 작업자가 협력
    4. 관리자와 작업자 간 책임과 업무의 적절한 분담(계획은 관리자, 실행은 작업자)

    주요 수단: 시간연구·동작연구, 차별적 성과급제(과업 달성 시 높은 임률), 기능식 직장제도, 작업지도표, 표준화(공구·작업 조건)

    과학적 관리법의 계승자: 길브레스 부부(동작연구·서블릭), 간트(간트 차트·과업 상여제), 에머슨(능률의 12원칙) — 이후 포드 시스템(동시관리)으로 발전했다.

    의의와 한계: 작업 측정·표준시간·IE의 출발점이 되었지만, 인간을 기계처럼 취급하고 노동 강화를 불렀다는 비판을 받았다. 포드 시스템과의 비교는 1.2.1을 참고한다.

    답안 작성 포인트

    • 배경 → 4대 원칙 → 주요 수단 → 의의와 한계 순서로 쓰고, 시간·동작 연구가 이 장(작업측정)의 기원임을 연결한다.
    • 의견 예: "데이터에 근거해 최선의 방법을 찾는다는 정신은 오늘날 스마트공장의 데이터 기반 운영으로 이어지며, 인간 존중(참여·자율)을 보완해 계승해야 한다."
    관련 기출 1문항 (121회)
    • 제121회(2020) 1교시 5번 · 10점
      Taylor의 과학적 관리법(Scientific Management)

    답안 작성 예시¶

    25점 예시: 제136회 3교시 1번 — 표준작업시간(ST)의 정의와 활용 용도

    1. 개요

    • 표준시간: 정해진 방법·조건에서 알맞은 숙련도의 작업자가 정상 속도로 1단위 작업을 끝내는 데 필요한 시간 — 테일러 시간연구에서 출발한 생산관리의 기준값
    • 생산계획·원가·능률 평가를 잇는 공통 언어라는 점을 첫 문단에 밝힌다

    2. 본론

    • (1) 정의와 구성: 식 \( ST = NT \times (1 + A) \), [그림] 관측시간 → 정미시간 → 표준시간 흐름도
    • (2) 구비 조건: 정확성·공정성·달성 가능성 + 작업 조건 7가지(127회 내용 재활용)
    • (3) 설정 방법: [그림] 직접·간접측정 분류도, [표] 5가지 방법 장단점(133회 표)
    • (4) 활용 용도: [표] 생산·일정계획 / 인원·설비 산정 / 라인밸런싱 / 원가·견적 / 능률 평가·성과급 / 개선 효과 측정 — 용도별 "어떻게 쓰는가" 한 줄씩
    • (5) 유지 관리: 작업 변경 시 개정, PAC로 작업 능률과 가동률 구분 관리

    3. 결론(기술사 의견)

    • 표준시간의 정확도가 계획·원가의 정확도를 결정하므로 정기 재검토가 필수
    • 차별화: MES 실적·영상 AI로 실제 사이클타임을 상시 수집해 표준과의 차이를 관리하는 디지털 표준시간 관리 제시

    25점 예시: 제130회 2교시 5번 — 여유율 설명, 일반여유·특수여유 구분

    1. 개요

    • 여유시간: 정미시간 외에 불규칙하게 생기는 피할 수 없는 지연과 피로를 보상하는 시간, 표준시간 = 정미시간 + 여유시간

    2. 본론

    • (1) 여유율: 외경법 \( A = \text{여유}/\text{정미} \), 내경법 \( A = \text{여유}/(\text{정미}+\text{여유}) \), 각각의 표준시간 식과 관계식 \( A_o = A_i/(1-A_i) \)
    • (2) 여유율 결정 방법: [표] 워크샘플링·연속 관측·여유율표·사내 규정
    • (3) 일반여유: [표] 작업·직장·용달·피로여유 — 정의와 예
    • (4) 특수여유: [표] 기계간섭·조·소로트·장사이클·관리여유 — 발생 조건
    • (5) 간단한 수치 예: 정미 2.218분, 여유율 25% → 외경 2.77분 / 내경 2.96분(121회 풀이 인용)

    3. 결론(기술사 의견)

    • 관리여유는 "관리 부실의 보정치"이므로 줄여 나갈 목표로 관리
    • 차별화: 피로여유는 인간공학적 작업 개선으로, 직장여유는 자재·지시 체계 개선으로 축소 → 표준시간 단축과 원가 경쟁력 연결
