    6.4.1 선형계획법(LP)¶

    선형계획법(LP)의 정의와 일반식 (76·91회)¶

    선형계획법은 한정된 자원의 제약(선형 부등식) 아래에서 목적(이익 최대·비용 최소)을 나타내는 선형 함수를 최적화하는 수리계획 기법이다.

    \[ \text{목적함수: } \max(\min)\ Z = \sum_{j} c_j x_j, \qquad \text{제약조건: } \sum_{j} a_{ij} x_j \le (\ge, =)\ b_i, \qquad \text{비음조건: } x_j \ge 0 \]
    구성 의미
    의사결정변수 \( x_j \) 결정해야 할 양(제품별 생산량 등)
    목적함수 최대화·최소화하려는 목표(이익·비용)
    제약조건 자원(시간·재료·능력)의 한계
    비음조건 변수는 음수가 될 수 없음

    LP의 가정(필수 조건) (68·73·91회)¶

    1. 비례성: 목적함수·제약조건의 각 항이 변수에 비례(규모의 경제 없음)
    2. 가법성: 각 변수의 기여도를 단순 합산할 수 있음(상호작용 없음)
    3. 분할성: 변수가 연속값(소수)을 가질 수 있음
    4. 확정성: 모든 계수(\( c_j, a_{ij}, b_i \))가 확정적으로 알려져 있음

    LP·IP·GP의 비교 (73회)

    구분 LP(선형계획) IP(정수계획) GP(목표계획)
    변수 연속 정수(또는 0·1) — 분할성 가정 완화 연속(또는 정수)
    목적 단일 목적 단일 목적 여러 목표를 우선순위에 따라 달성
    특징 심플렉스로 효율적 해법 해법이 복잡(분지한계법) 목표와의 편차(미달·초과)를 최소화
    적용 제품 배합, 생산계획 설비 배치, 할당, 투자 선택 이익·고용·품질 등 상충 목표

    적용 분야 (76·82·121회): ① 제품 배합(생산 믹스) 결정 ② 원료 배합(사료·석유 정제) ③ 생산·재고 계획(총괄생산계획) ④ 수송·물류 계획 ⑤ 인력 배치·일정 계획 ⑥ 투자 포트폴리오 선택

    해법의 종류 (76·103회)

    해법 장점 단점
    도시법(그래프법) 해의 의미를 시각적으로 이해, 민감도 분석이 직관적 변수가 2개일 때만 사용 가능
    심플렉스법 변수·제약이 많아도 체계적으로 해를 구함, 컴퓨터 처리 가능 계산 과정이 복잡, 직관적 이해 어려움
    (기타) 내부점법, 쌍대 심플렉스법, 컴퓨터 소프트웨어 대규모 문제 –

    풀이: 88회¶

    \[ \max Z = 12A + 15B \quad \text{s.t.} \quad 4A + 2B \le 120\ (\text{용접}),\ \ 3A + 5B \le 100\ (\text{연마}),\ \ A, B \ge 0 \]
    꼭짓점 (A, B) Z(만 원)
    (0, 0) 0
    (30, 0) 360
    (0, 20) 300
    (28.57, 2.86) — 두 제약식의 교점 385.7

    → 최적해 A = 200/7 ≈ 28.6단위, B = 20/7 ≈ 2.9단위, 최대 이익 ≈ 385.7만 원. (정수로 생산해야 하면 A = 28, B = 3에서 381만 원)

    풀이: 97회¶

    \[ \max Z = 1{,}000A + 1{,}500B \quad \text{s.t.} \quad 10A + 18B \le 3{,}200,\ \ 15A + 5B \le 2{,}500,\ \ A, B \ge 0 \]

    (참고) 두 제약식의 교점 A ≈ 131.8, B ≈ 104.5에서 Z ≈ 288,636원이 최대다.

    현실 적용 시 예상 문제점: ① 해가 소수로 나와 정수 생산량으로 조정 필요 ② 계수(소요시간·이익)가 실제로는 변동(확정성 가정 위배) ③ 시장 수요 한계, 원자재·인력 제약 등 모형에 빠진 조건 ④ 대량 생산 시 단위 이익이 변하는 비선형성 ⑤ 품종 전환(준비교체) 시간 미반영

    풀이: 103회 (텐트 X1, 그늘막 X2)¶

    \[ \max Z = 20{,}000X_1 + 10{,}000X_2 \quad \text{s.t.} \quad 6X_1 + 4X_2 \le 2{,}400,\ \ 4X_1 \le 1{,}500,\ \ 9X_1 + 3X_2 \le 2{,}700,\ \ X_1, X_2 \ge 0 \]
    꼭짓점 (X1, X2) Z(원)
    (0, 600) 6,000,000
    (300, 0) 6,000,000
    (200, 300) — 인발·조립 제약의 교점 7,000,000

    → 텐트 200개, 그늘막 300개, 최대 이익 700만 원. 후가공 제약(4X1 ≤ 1,500)은 여유가 있다(800시간 사용).

    풀이: 121회 (제품1 x₁, 제품2 x₂)¶

    \[ \max Z = 30x_1 + 50x_2 \quad \text{s.t.} \quad x_1 \le 6,\ \ 2x_2 \le 14,\ \ 2x_1 + 2x_2 \le 18,\ \ x_1, x_2 \ge 0 \]
    꼭짓점 (0, 7) (2, 7) (6, 3) (6, 0)
    Z(만 원) 350 410 330 180

    → 최적해 x₁ = 2, x₂ = 7, 주당 최대 이익 410만 원

    민감도 분석(잠재가격): 최적점에서 공장2·공장3의 제약이 묶여(binding) 있다. 쌍대 조건 \( 2y_3 = 30,\ 2y_2 + 2y_3 = 50 \)에서

    • 공장2의 1시간 가치 = 10만 원, 공장3의 1시간 가치 = 15만 원
    • 공장1은 여유(4시간)가 있으므로 1시간의 가치는 0이다.

    그래프로 보면 공장3의 시간을 1시간 늘리면 제약선이 바깥으로 이동해 최적점이 (2.5, 7)로 옮겨 가고 이익이 15만 원 늘어난다.

    LP 풀이의 일반 절차¶

    개요용 배경: LP는 2차 세계대전 중 군수 계획 문제에서 출발해, 1947년 G. B. Dantzig가 심플렉스법을 개발하면서 경영과학(OR)의 대표 기법이 되었다.

    도시법(변수 2개)

    1. 의사결정변수 정의(단위 포함) → 목적함수·제약조건·비음조건 정식화
    2. 각 제약식을 등식으로 보고 두 절편을 구해 직선을 그림 → 부등호 방향으로 실행가능영역 표시
    3. 꼭짓점 좌표 계산(두 직선의 연립방정식)
    4. 꼭짓점마다 Z 계산(꼭짓점 비교표) 또는 등이익선 평행 이동 → 최적해
    5. 묶인(binding) 제약과 여유(slack) 제약 확인 → 잠재가격·해석

    심플렉스법(변수 3개 이상)

    1. 표준형 변환: \( \le \) 제약에 여유변수(slack), \( \ge \) 제약에 잉여변수(surplus)와 인위변수 추가
    2. 초기 기저해(원점)로 시작하는 심플렉스 표 작성
    3. 진입변수: 목적함수 행에서 개선 효과가 가장 큰 변수(최대화에서 \( c_j - z_j \)가 가장 큰 양수)
    4. 탈락변수: 최소비율 검사(우변 ÷ 진입 열의 양수 계수가 최소인 행)
    5. 피벗 연산으로 표 갱신 → 더 개선할 변수가 없을 때 최적

    특수한 경우: 해가 없음(실행 불가능), 무한해(제약이 열려 있음), 복수 최적해(목적함수가 제약선과 평행), 퇴화

    쌍대성과 민감도 분석: 모든 LP(원문제)에는 쌍대문제가 있으며, 쌍대변수 값이 각 자원의 잠재가격(Shadow Price) — 자원 1단위 증가 시 목적함수 증가분이다. 민감도 분석은 계수(\( c_j \))와 자원량(\( b_i \))이 변해도 최적 기저가 유지되는 범위를 구해 확정성 가정의 한계를 보완한다.

    최근 동향: 엑셀 해 찾기·상용 솔버로 대규모 문제를 즉시 풀 수 있어, 실무 역량은 정식화(모델링)와 결과 해석에 있다. APS(7.1.6)·총괄생산계획(3.1.1)의 최적화 엔진이 LP·MIP 기반이다.

    할당 문제 (88회)¶

    0·1 변수 \( x_{ij} \)(작업 i를 기계 j에 배정하면 1)로 정식화한다.

    \[ \min Z = \sum_i \sum_j t_{ij} x_{ij} \quad \text{s.t.} \quad \sum_j x_{ij} = 1\ (\text{각 작업은 한 기계}),\ \ \sum_i x_{ij} = 1\ (\text{각 기계는 한 작업}),\ \ x_{ij} \in \{0, 1\} \]

    헝가리안법 절차와 88회 적용

    1. 행 감소: 각 행에서 그 행의 최솟값을 뺀다.
    2. 열 감소: 각 열에서 그 열의 최솟값을 뺀다.
    3. 모든 0을 덮는 최소 직선 수가 n(행 수)이면 0 위치로 배정, 아니면 4로
    4. 덮이지 않은 칸의 최솟값을 덮이지 않은 칸에서 빼고, 두 선이 교차하는 칸에 더한 뒤 3으로
    단계 작업1 (A, B, C) 작업2 (A, B, C) 작업3 (A, B, C)
    원 행렬 2, 4, 7 4, 2, 1 2, 6, 5
    행 감소 0, 2, 5 3, 1, 0 0, 4, 3
    열 감소(B열 −1) 0, 1, 5 3, 0, 0 0, 3, 3
    직선 2개(A열·작업2 행) < 3 → 최솟값 1 조정 0, 0, 4 4, 0, 0 0, 2, 2

    수송 문제 보충

    • 불균형 문제: 공급 > 수요이면 가상 수요지(비용 0), 수요 > 공급이면 가상 공급지를 추가해 균형을 맞춘다.
    • 기저 배정 칸 수는 \( m + n - 1 \)개(m: 공급지 수, n: 수요지 수)여야 한다. 모자라면 퇴화이므로 0을 배정한 칸을 추가해 개선법을 적용한다(91회: 3 + 4 − 1 = 6칸 ✓).
    • 최적성 검사: 징검다리법(빈 칸마다 폐회로를 만들어 비용 변화 계산)·MODI법(\( u_i + v_j = c_{ij} \)로 잠재비용을 구해 빈 칸의 개선 지수 \( c_{ij} - u_i - v_j \) 계산) — 개선 지수가 모두 0 이상이면 최적이다.
    • 적용: 다공장–다창고 물류 계획, 공장·물류센터 입지 비교(1.2.3), 할당 문제는 작업자–기계·작업 배정에 쓴다.

    답안 작성 포인트

    • 수송 문제는 세 가지 최초 가능해 방법의 비교 → 지정된 방법으로 배정표 작성 → 총비용 순서로 쓴다. 공급 합계와 수요 합계가 같은지(균형) 먼저 확인한다.
    • 차별화: \( m + n - 1 \) 조건 확인과 MODI법에 의한 최적성 검사 방향을 한 줄 덧붙이고, 할당 문제는 헝가리안법 단계표로 푼다.
    • 결론 예: "최초 가능해는 VAM이 최적해에 가장 가깝고, 최종적으로 MODI법으로 최적성을 검증해야 한다. 실무에서는 운송 용량·리드타임·탄소 배출 제약을 추가한 네트워크 최적화로 확장한다."

    6.4.3 대기행렬 이론¶

    대기행렬의 의의와 구조 (91·97회)¶

    대기행렬 이론은 고객이 서비스를 받으려고 기다리는 현상을 확률 모형으로 분석해, 대기 비용과 서비스 비용의 합이 최소가 되는 서비스 수준(창구·설비 수)을 정하는 기법이다.

    모형화에 필요한 정보 (97회, 수리공장의 예)

    1. 도착 과정: 고장 설비가 도착하는 율(λ)과 분포(포아송)
    2. 서비스 과정: 수리공의 수리율(μ)과 서비스 시간 분포(지수)
    3. 서비스 창구 수: 수리공(수리 라인)의 수
    4. 대기 규칙과 용량: 선착순 등 우선순위, 대기 공간의 한계, 고객 모집단의 크기

    구조별 분류 (91회): 단일 창구·단일 단계 / 복수 창구·단일 단계 / 단일 창구·복수 단계 / 복수 창구·복수 단계

    분석 절차: 시스템 정의 → 도착·서비스 자료 수집과 분포 확인 → 모형 선택(M/M/1 등) → 성과 척도 계산 → 비용 분석·대안 비교 → 최적 서비스 수준 결정

    M/M/1 모형 (97·103회)¶

    가정: ① 도착은 포아송분포(도착 간격은 지수분포) ② 서비스 시간은 지수분포 ③ 단일 창구, 선착순, 무한 모집단·무한 대기 공간, λ < μ(정상 상태)

    \[ \rho = \frac{\lambda}{\mu}, \quad L_s = \frac{\lambda}{\mu - \lambda}, \quad L_q = \frac{\lambda^2}{\mu(\mu - \lambda)}, \quad W_s = \frac{1}{\mu - \lambda}, \quad W_q = \frac{\lambda}{\mu(\mu - \lambda)} \]

    풀이: 91회¶

    μ = 12건/시간, λ = 60 ÷ 6 = 10건/시간

    • 시스템 내 평균 소비시간 \( W_s = \dfrac{1}{12 - 10} = 0.5\text{시간} = \mathbf{30\text{분}} \)
    • 평균 대기시간 \( W_q = \dfrac{10}{12 \times 2} = 0.417\text{시간} = \mathbf{25\text{분}} \)

    풀이: 103회¶

    • 도착률 λ = 40명 ÷ 10시간 = 4명/시간
    • 서비스율 μ = 60분 ÷ 10분 = 6명/시간
    • 시스템 내 평균 고객 수 \( L_s = \dfrac{4}{6 - 4} = \mathbf{2\text{명}} \)

    계량 모델 비교 (124회)¶

    모델 특징 응용 분야
    선형계획 선형 제약에서 최적해(확정적) 생산 믹스, 배합, 수송
    대기행렬 확률적 도착·서비스의 대기 현상 분석 창구·설비 수, 정비 인력, 물류 도크
    시뮬레이션 복잡·확률적 시스템을 모의 실험 공장 배치, 생산 라인, 재고 정책 검증

    켄달 기호와 리틀의 법칙¶

    개요용 배경: 대기행렬 이론은 1909년 덴마크의 A. K. Erlang이 전화 교환 설비의 혼잡 문제를 분석하며 시작되었고, D. G. Kendall이 모형 표기법(1953)을 정리했다.

    켄달 기호 A / B / c / K / N / D 의미 예
    A 도착 간격 분포 M(지수=포아송 도착), D(일정), G(일반)
    B 서비스 시간 분포 M, D, G, \( E_k \)(얼랑)
    c 서버(창구) 수 1, s
    K 시스템 용량(생략 시 무한) 대기 공간 한계
    N 고객 모집단 크기(생략 시 무한) 수리공장의 설비 대수(유한)
    D 대기 규칙(생략 시 FCFS) 우선순위, LCFS

    리틀의 법칙(Little's Law): \( L = \lambda W \) — 분포와 관계없이 성립하며, \( L_s = \lambda W_s \), \( L_q = \lambda W_q \), \( W_s = W_q + 1/\mu \)이다. 공장에서는 재공재고 = 투입률 × 리드타임으로 쓰인다.

    보충 계산(위 풀이의 나머지 성과 척도)

    문제 ρ(이용률) \( L_s \) \( L_q \) \( W_s \) \( W_q \)
    91회(λ = 10, μ = 12) 0.833 5건 4.17건 30분 25분
    103회(λ = 4, μ = 6) 0.667 2명 1.33명 30분 20분

    (검산: 91회 \( L_s = \lambda W_s = 10 \times 0.5 = 5 \) — 리틀의 법칙과 일치)

    최적 서비스 수준(비용 모형): 서버(수리공·설비)를 늘리면 서비스 비용은 증가하고 대기 비용(설비 정지 손실·고객 이탈)은 감소한다. 총비용 = 서비스 비용 + 대기 비용이 최소가 되는 서버 수를 고른다. ρ가 1에 가까워지면 대기가 급증하므로(91회 ρ = 0.83에서 대기 4건 이상), 이용률 100%를 목표로 하는 것은 오히려 비효율적이다.

    적용 분야: 정비 인력 수 결정, 공구실·검사대 창구 수, 하역 도크·AGV 대수, 병목 공정 앞 버퍼 크기, 콜센터·A/S 인원

    답안 작성 포인트

    • M/M/1 문제는 λ·μ를 같은 시간 단위로 맞추고, 공식과 결과(단위 포함)를 쓴다. 적용 조건(포아송·지수·λ < μ)을 빠뜨리지 않는다.
    • 차별화: 켄달 기호, 리틀의 법칙 검산, 총비용 곡선(서비스 비용 + 대기 비용) 그림을 덧붙인다.
    • 결론 예: "대기행렬 분석은 서비스 수준과 비용의 균형점을 찾는 도구이며, 이용률을 무리하게 높이면 대기가 급격히 늘어나므로 적정 여유 능력을 유지해야 한다. 가정이 맞지 않는 복잡한 시스템은 시뮬레이션으로 보완한다."

    의사결정의 상황 구분 (106·127회)¶

    상황 의미 기법
    확실성하 각 대안의 결과를 확실히 앎 LP, 손익분기 분석
    위험하 상황의 발생 확률을 앎 기대값(EMV) 기준, 의사결정나무

    4) 의뢰 여부 EMV(d1) = 0.7 × 76 + 0.3 × 0 − 10 = 43.2 > EMV(d2) = 40 의뢰

    5) 종합 결정: 사업성 분석을 의뢰하고, 분석이 잘 되면 거점창고를 설치하고 잘 되지 않으면 설치하지 않는다. 분석의 가치(53.2 − 40 = 13.2억 원)가 비용(10억 원)보다 크다.

    AHP와 ANP (97·115·121회)¶

    AHP(계층분석과정): T. Saaty가 개발한 다기준 의사결정 기법으로, 문제를 목표 → 평가 기준 → 대안의 계층으로 나누고 요소들을 쌍대 비교해 가중치를 구한다.

    • 기본 공리 4가지: ① 역수성(A가 B보다 a배 중요하면 B는 A의 1/a배) ② 동질성(비교 요소는 같은 척도로 비교 가능한 범위) ③ 독립성(계층 간 요소는 서로 독립) ④ 기대성(계층 구조에 의사결정에 필요한 요소가 모두 포함됨)
    • 쌍대 비교 (121회): 같은 계층의 두 요소를 1~9점 척도(1: 같음, 3: 약간, 5: 중요, 7: 매우, 9: 극히 중요)로 비교한 행렬을 만들고 고유벡터로 가중치를 구한다. 일관성 비율(CR) 0.1 이하이면 판단이 일관된 것으로 본다.

    ANP(네트워크 분석과정) (115회): AHP를 확장해 요소 간 상호 의존성과 피드백을 허용하는 네트워크 구조로 가중치를 구한다. 기준끼리 영향을 주고받는 현실 문제에 적합하지만 비교 횟수가 많다.

    위험하 의사결정 기준 (127회)¶

    기준 방법 특징
    기대값 기준(EMV) \( EMV_i = \sum_j p_j \times R_{ij} \)가 최대인 대안 가장 널리 쓰임, 반복 의사결정에 적합
    기대 기회손실(EOL) 기준 기회손실의 기대값이 최소인 대안 EMV 기준과 같은 결론, 최소 EOL = EVPI
    최우(最尤) 기준 발생 확률이 가장 큰 상황에서 최선인 대안 간편, 다른 상황 무시
    기대값–분산 기준 기대값이 크고 분산(위험)이 작은 대안 위험 회피 성향 반영
    요구수준(만족) 기준 목표 수준 이상을 달성할 확률이 최대인 대안 최소 성과 확보가 중요할 때
    기대효용 기준 금액 대신 효용의 기대값 최대 의사결정자의 위험 태도 반영

    완전정보의 기대가치(EVPI): 미래 상황을 미리 정확히 안다면 얻을 수 있는 기대 이익의 증가분으로, 정보 획득(조사·분석)에 지불할 수 있는 상한이다.

    \[ EVPI = \text{완전정보하의 기대이익}(EVwPI) - \text{정보 없이 최선인 EMV} \]

    예(115회, 분석 미의뢰 상황): 완전정보라면 시장성이 좋을 때만 설치 → 0.5 × 100 + 0.5 × 0 = 50억 원, 정보 없는 최선 EMV = 40억 원 → EVPI = 10억 원

    115회 자료의 정합성

    분석을 의뢰할 때 시장성이 좋을 전체 확률은 0.7 × 0.8 + 0.3 × 0.1 = 0.59로, 의뢰하지 않을 때의 사전확률 0.5와 맞지 않는다(베이즈 정리상 같아야 함). 그래서 표본정보의 가치(13.2억 원)가 EVPI(10억 원)보다 크게 나오는데, 이론상 표본정보의 가치는 EVPI를 넘을 수 없다. 답안은 문제 조건대로 풀고, 이 점을 한 줄 언급하면 차별화된다.

    AHP의 수행 절차와 계산 예 (97·121회)¶

    1. 문제를 계층 구조로 분해(목표 → 평가 기준 → (하위 기준) → 대안)
    2. 같은 계층 요소 간 쌍대 비교 행렬 작성(1~9점 척도, 역수 대칭)
    3. 고유벡터(또는 기하평균 근사)로 가중치 계산
    4. 일관성 검증: \( CI = \dfrac{\lambda_{max} - n}{n - 1} \), \( CR = \dfrac{CI}{RI} \le 0.1 \) (RI: 무작위 지수, n = 3이면 0.58, n = 4이면 0.90)
    5. 계층별 가중치를 곱해 합산(종합 가중치) → 대안 순위 결정

    계산 예(설비 선정 기준 3개)

    기준 가격 품질 납기 행 기하평균 가중치
    가격 1 3 5 2.466 0.637
    품질 1/3 1 3 1.000 0.258
    납기 1/5 1/3 1 0.405 0.105

    \( \lambda_{max} \approx 3.039 \), CI ≈ 0.019, CR ≈ 0.019 ÷ 0.58 ≈ 0.033 ≤ 0.1 → 일관성 있음

    답안 작성 포인트

    • 불확실성 기준은 기준별 계산 열을 붙인 표 하나로 모든 기준의 결과를 보여 준다. Savage는 후회 행렬을 먼저 만든다.
    • 의사결정나무는 나무 그림(결정 □, 확률 ○) → 뒤에서부터 EMV 역산(rollback) 순서로 쓴다.
    • 차별화: 정보의 가치(EVPI)와 AHP의 일관성 비율(CR) 계산을 덧붙이고, 127회형은 확실성·위험·불확실성의 3상황 표 + 기준별 방법을 모두 쓴다.
    • 결론 예: "어느 기준을 택하느냐는 의사결정자의 위험 태도에 달려 있으므로 여러 기준의 결과를 함께 제시하고, 확률 정보를 얻을 수 있으면 EMV·의사결정나무로, 정성 기준이 많으면 AHP로 보완해야 한다. 최근에는 빅데이터·AI 예측으로 상황 확률을 추정해 불확실성을 위험 상황으로 바꾸는 방향으로 발전하고 있다."

    프로젝트 관리 (76·94·97·106회)¶

    프로젝트는 정해진 기간·예산 안에 고유한 결과물을 만드는 한시적 활동이다.

    • 프로젝트의 특징 (97회): ① 한시성(시작과 끝) ② 고유성(유일한 결과물) ③ 점진적 구체화·불확실성

    • 프로젝트 관리의 전략적 의미 (106회): 전략을 실행 가능한 프로젝트로 바꾸는 수단 — 시장 출시 시간 단축, 자원의 효율적 배분, 위험 관리
    • 관리 절차 (106회): 착수 → 계획(범위·WBS·일정·원가·자원) → 실행 → 감시·통제 → 종료
    • 영역별 프로세스 구성 요소 (76·94회, PMBOK): 통합, 범위, 일정, 원가, 품질, 자원, 의사소통, 리스크, 조달, 이해관계자 관리

    네트워크의 용어와 작성 원칙 (82·91회)¶

    용어 의미
    활동(Activity) 시간·자원이 드는 작업 — AOA에서는 화살표
    단계(Event)·결합점(Node) 활동의 시작·끝 시점 — AOA에서는 원
    호(Arc) 노드를 잇는 선(화살표)
    가상활동(Dummy) 시간·자원이 없는 가상의 활동(점선) — 선후관계 표현용
    여유활동(Slack Activity) 여유시간이 있는 활동
    경로(Path) 시작에서 끝까지 이어진 활동의 연결
    주경로(Critical Path) 여유시간이 0인 활동으로 이어진 가장 긴 경로 — 프로젝트 완료 시간을 결정
    주활동(Critical Activity) 주경로 위의 활동 — 지연되면 프로젝트 전체가 지연

    작성 원칙: 시작·종료 결합점은 하나, 화살표는 왼쪽에서 오른쪽으로, 두 결합점 사이에는 활동 하나(필요하면 더미 사용), 순환(루프) 금지, 결합점 번호는 앞이 작게

    작성 절차: 활동 목록과 선후관계 정리 → 네트워크도 작성 → 활동 시간 추정 → 전진 계산(ES·EF) → 후진 계산(LS·LF) → 여유시간·주경로 결정

    \[ \text{총여유} = LS - ES = LF - EF \]

    PERT와 CPM (71·76·139회)¶

    구분 PERT CPM
    개발 1958년 미 해군 폴라리스 미사일 계획 1957년 듀폰사 공장 보전
    시간 추정 3점 추정(낙관·최빈·비관) — 확률적 1점 추정 — 확정적
    중점 일정 관리, 완료 확률 시간–비용 상충(일정 단축 비용 최소화)
    적용 경험이 없는 신규 연구개발 경험이 있는 반복 공사

    PERT의 시간 계산

    \[ t_e = \frac{a + 4m + b}{6}, \qquad \sigma^2 = \left( \frac{b - a}{6} \right)^2, \qquad Z = \frac{T_s - T_e}{\sqrt{\sum \sigma^2_{CP}}} \]

    PERT/TIME 절차 (91회): 활동·선후관계 정의 → 네트워크 작성 → 3점 시간 추정과 \( t_e, \sigma^2 \) 계산 → 전진·후진 계산 → 주경로·여유 결정 → 완료 확률 계산 → 일정 통제

    PERT/COST 5단계 (91회): ① 작업분류체계(WBS)와 작업 패키지 정의 ② 활동별 예산(원가) 배정 ③ 일정 계획에 따른 기간별 예산 계획 ④ 실제 원가·진척 측정 ⑤ 계획 대비 원가·일정 차이 분석과 통제

    CPM의 일정 단축(Crashing): 주경로 위의 활동 중 비용 구배가 가장 작은 활동부터 단축한다. 단축하다가 새 주경로가 생기면 여러 경로를 함께 줄인다.

    \[ \text{비용 구배} = \frac{\text{특급 비용} - \text{정상 비용}}{\text{정상 시간} - \text{특급 시간}} \]

    주경로와 애로 사슬(CCPM) (94·106·115회)¶

    CCPM(Critical Chain Project Management)은 골드랫의 제약이론(TOC)을 프로젝트에 적용한 방법이다.

    구분 Critical Path Critical Chain
    정의 활동의 선후관계만 고려한 가장 긴 경로 선후관계 와 자원 제약을 함께 고려한 가장 긴 경로
    시간 추정 활동마다 안전 여유 포함 활동 시간을 50% 수준으로 줄이고 여유를 모아 버퍼로 관리
    버퍼 없음(개별 활동에 숨어 있음) 프로젝트 버퍼(끝), 합류 버퍼(비주경로 합류점), 자원 버퍼
    관리 활동별 완료일 관리 버퍼 소진율로 진척 관리
    목적 일정 계산 학생 증후군·파킨슨 법칙 방지, 일정 단축

    \( t_e \) 4 6 5 7 6 9 9

    네트워크: A → B → C → D → E (C는 A·B 후, D는 B·C 후) — 사실상 하나의 경로

    • 정상 완료시간 = 4 + 3 + 5 + 2 + 1 = 15일, 정상 비용 = 500 + 600 + 700 + 300 + 300 = 2,400만 원
    • 비용 구배('단축시간'을 단축 후 소요시간으로 해석): A (1,000 − 500) ÷ 2 = 250, B (800 − 600) ÷ 1 = 200, C (1,400 − 700) ÷ 2 = 350, D (600 − 300) ÷ 1 = 300(만 원/일)
    • 1일 단축: 비용 구배가 가장 작은 B를 1일 단축 → 14일, 2,600만 원

    ('단축시간'을 단축 가능 일수로 해석하면 B의 비용 구배가 100만 원/일이 되어 14일, 2,500만 원 — 문제의 의미를 밝히고 푼다.)

    103회 일정 단축 문제에 대해¶

    이 문제는 활동별 시간·비용과 비용 구배는 주어졌지만 선행 관계(네트워크)가 자료에 없어 여기서는 풀이를 생략한다. 원 문제의 네트워크를 이용해 ① 정상 시간으로 주경로·정상 비용(35,000달러)을 구하고 ② 주경로 위 활동을 비용 구배가 작은 순서로 단축하되, 새 주경로가 생기면 병행 단축해 최단 일정과 그때의 비용을 구한다.

    네트워크 그림 예 — 124회 AON¶

    flowchart LR
    S(("시작")) --> A["A 3"] --> B["B 6"] --> C["C 12"] --> D["D 2"] --> H["H 1"] --> E2(("종료"))
    S --> E["E 6"] --> F["F 10"] --> G["G 5"] --> H

    (주경로 A–B–C–D–H = 24일은 굵게 표시하고, 각 노드에 ES·EF·LS·LF를 적어 넣는다. AOA에서는 활동을 화살표로, 결합점을 원으로 그린다.)

    CPM 일정 단축(Crashing)의 일반 절차¶

    1. 정상 시간으로 네트워크를 그리고 주경로·정상 완료시간·정상 총비용(활동 정상비용의 합)을 구한다.
    2. 활동별 비용 구배와 최대 단축 가능 일수를 표로 정리한다.
    3. 주경로 위에서 비용 구배가 가장 작은 활동을 1일(또는 가능한 만큼) 단축한다.
    4. 모든 경로 길이를 다시 계산한다 — 주경로가 여러 개가 되면 각 주경로에서 하나씩 동시에 단축하는 조합 중 구배 합이 최소인 것을 고른다.
    5. 목표 일정에 도달하거나 주경로 활동을 더 줄일 수 없을 때(최단 일정)까지 반복한다.
    6. 총비용 = 정상비용 + 누적 단축비용(간접비가 주어지면 직접비 + 간접비가 최소인 최적 공기를 찾음)

    6.4.6 시뮬레이션과 DEA¶

    시뮬레이션 (88·112회)¶

    의의: 실제 시스템을 컴퓨터 모델로 만들어 모의 실험하며, 해석적으로 풀기 어려운 복잡·확률적 시스템의 성과를 예측하고 대안을 비교하는 기법이다.

    장점 단점
    복잡하고 확률적인 시스템도 분석 가능 모델 개발에 시간·비용이 듦
    실제 시스템을 바꾸지 않고 다양한 대안 실험 최적해를 보장하지 않음(대안 비교)
    시간을 압축해 장기간의 결과를 빠르게 확인 입력 자료·모델이 부정확하면 결과도 부정확
    결과를 시각화해 이해·설득에 유리 결과 해석에 통계 지식 필요

    생산·공정관리 적용 분야: 설비배치·물류 흐름, 생산 라인 설계(병목·버퍼 크기), 재고 정책, 일정계획, 설비 대수·인원 결정, 공급망 설계, 디지털 트윈

    수행 절차: ① 문제 정의와 목표 설정 → ② 시스템 분석과 자료 수집(분포 추정) → ③ 모델 작성 → ④ 검증(Verification)·타당성 확인(Validation) → ⑤ 실험 계획 → ⑥ 실행과 결과 분석 → ⑦ 대안 평가·실행

    DEA(자료포락분석) (100회)¶

    DEA(Data Envelopment Analysis)는 여러 투입·산출 요소를 가진 비슷한 의사결정 단위(DMU: 공장·지점·부서)의 상대적 효율성을 선형계획으로 평가하는 비모수적 성과평가 도구다.

    • 원리: 가장 효율적인 DMU들로 효율 경계(프런티어)를 만들고, 각 DMU가 경계에서 얼마나 떨어져 있는지로 효율성(0~1)을 측정한다.
    • 특징: 여러 투입·산출을 동시에 고려, 가중치를 사전에 정하지 않음, 비효율 DMU의 개선 목표와 벤치마킹 대상 제시
    • 모형: CCR 모형(규모 수익 불변), BCC 모형(규모 수익 가변)
    • 한계: 상대적 효율성일 뿐 절대 수준은 아님, 이상치·변수 선택에 민감
    \[ \text{효율성}_k = \frac{\sum_r u_r y_{rk}}{\sum_i v_i x_{ik}} \le 1 \quad (u_r, v_i: \text{각 DMU에 가장 유리하게 LP로 정한 산출·투입 가중치}) \]

    (Charnes, Cooper, Rhodes가 1978년 CCR 모형으로 제안 — 효율성 1인 DMU가 효율 경계를 이룬다.)

    시뮬레이션의 종류와 보충¶

    종류 내용 공장 적용 예
    몬테카를로 시뮬레이션 난수로 확률변수를 반복 표본 추출해 결과 분포를 추정 투자 위험 분석, 수요 불확실성하 재고 정책
    이산 사건 시뮬레이션(DES) 도착·가공·고장 같은 사건 발생 시점마다 상태 변화 생산 라인·물류 흐름, 병목·버퍼 분석
    연속(시스템 다이내믹스) 피드백 구조를 미분 방정식으로 표현 공급망 채찍효과, 장기 능력 계획
    에이전트 기반 개별 주체(작업자·AGV)의 행동 규칙으로 전체 현상 재현 AGV 교통 관제, 작업자 동선

    몬테카를로 절차: 확률분포 결정 → 누적확률분포 작성 → 난수 구간 배정 → 난수로 상황 생성 → 반복 실험 → 결과 통계 분석

    • 검증(Verification): 모델이 의도한 논리대로 올바르게 만들어졌는가(디버깅)
    • 타당성 확인(Validation): 모델이 실제 시스템을 올바르게 나타내는가(실측치와 비교)
    • 디지털 트윈과의 관계: 기존 시뮬레이션은 설계 단계의 오프라인 실험이지만, 디지털 트윈은 IoT로 실시간 데이터를 받아 가상 모델을 계속 동기화하고 운영 의사결정까지 지원한다(4.5.3 가상제조, 7.1.2 스마트공장).

    답안 작성 포인트

    • 시뮬레이션은 의의 → 장단점 표 → 적용 분야 → 절차(검증·타당성 확인 포함) 순서로 쓴다.
    • 차별화: 시뮬레이션 종류 표(몬테카를로·DES 등)와 디지털 트윈으로의 발전을 덧붙인다.
    • 결론 예: "시뮬레이션은 최적해가 아니라 대안 비교 도구이므로 입력 자료의 정확성과 모델 타당성 확인이 핵심이며, 스마트공장에서는 실시간 데이터와 연동한 디지털 트윈으로 설계·운영 의사결정을 지원해야 한다."
    • DEA는 상대적 효율성과 효율 경계 개념을 그림(투입-산출 평면의 포락선)으로 보여 주면 좋다.

    답안 작성 예시¶

    25점 예시: 제130회 4교시 6번 — CPM 네트워크 작성, 정상 완료시간·비용, 1일 단축 시 소요시간과 비용

    1. 주어진 조건 정리

    • [표] 활동·선행활동·정상시간·정상비용·단축 자료 정리, "단축시간"의 해석(단축 후 소요시간 vs 단축 가능 일수)을 먼저 밝힌다.
    • CPM = 1점 추정, 시간–비용 상충 관리(듀폰, 1957) — 개요 1~2줄

    2. 공식

    • 전진·후진 계산(ES·EF·LS·LF), 총여유 = LS − ES
    • 비용 구배 = (특급 비용 − 정상 비용) ÷ (정상 시간 − 특급 시간)

    3. 계산표

    • (1) [그림] AON(또는 AOA) 네트워크 — C는 A·B 후, D는 B·C 후
    • (2) [표] ES·EF·LS·LF·여유 → 주경로 A–B–C–D–E, 정상 완료 15일, 정상 비용 2,400만 원
    • (3) [표] 활동별 비용 구배(A 250, B 200, C 350, D 300만 원/일)

    4. 판정

    • 주경로 위 최소 구배 B를 1일 단축 → 14일, 2,600만 원(다른 해석이면 2,500만 원 — 해석을 명시)

    5. 해석·의견

    • 추가 단축 시 다음 순서(A → D → C)와 한계, 간접비를 고려한 최적 공기 개념(총비용 곡선)을 언급한다.
    • 차별화 포인트: 해석의 모호성 명시, 단축 후 경로 재확인, CCPM·EVM 등 보완 기법 제시

    25점 예시: 제121회 2교시 5번 — LP 정식화, 도시법 최적해, 공장2·3의 1시간 가치(민감도 분석)

    1. 주어진 조건 정리

    • 변수 \( x_1, x_2 \): 제품1·2의 주당 생산량(개), 이익 30·50만 원/개, 공장별 가용시간 6·14·18시간

    2. 정식화(공식)

    • \( \max Z = 30x_1 + 50x_2 \), s.t. \( x_1 \le 6 \), \( 2x_2 \le 14 \), \( 2x_1 + 2x_2 \le 18 \), \( x_1, x_2 \ge 0 \)

    3. 계산표

    • (1) [그림] 세 제약선과 실행가능영역(꼭짓점 (0,0)·(6,0)·(6,3)·(2,7)·(0,7))
    • (2) [표] 꼭짓점별 Z → 최적 (2, 7), Z = 410만 원
    • (3) 민감도: 묶인 제약(공장2·3) 확인 → 쌍대 조건 \( 2y_3 = 30,\ 2y_2 + 2y_3 = 50 \) → 공장2 10만 원, 공장3 15만 원/시간, 공장1은 여유 4시간이므로 0
    • (4) [그림] 공장3 제약선을 1시간 바깥으로 이동 → 새 최적점 (2.5, 7), 이익 +15만 원

    4. 판정·해석

    • 공장3의 시간 증설 효과가 가장 크다 → 잔업·설비 증설은 시간당 비용이 잠재가격보다 작을 때만 경제적이다.
    • 차별화 포인트: LP 4가정과 정수 조건(현실 적용 한계), 잠재가격의 유효 범위(최적 기저가 유지되는 범위)를 한 줄 언급한다.
