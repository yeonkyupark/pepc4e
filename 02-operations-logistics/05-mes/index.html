    2.5.1 MES의 개념과 기능¶

    MES의 정의 (88·136회)¶

    MES(Manufacturing Execution System, 제조실행시스템)는 생산계획(ERP)과 현장 설비·작업자 사이에서, 작업 지시부터 완제품이 나올 때까지 생산 활동을 실시간으로 관리·통제·최적화하는 현장 중심의 정보시스템이다. MESA(MES 협회)는 이를 "주문 접수에서 완제품까지 생산 활동을 최적화하는 정보를 제공하는 시스템"으로 정의한다.

    등장 배경: 1990년대 초 미국 AMR Research가 MES라는 용어를 쓰기 시작했고, 1990년대 중반 MESA가 11가지 기능 모델(MESA-11)을 제시하며 체계화되었다. ERP의 계획과 현장 제어(PLC·SCADA) 사이의 정보 단절(계획-실행 간극)을 메우려는 필요에서 출발했다. 국내에서는 생산시점관리(POP)를 확장한 형태로 보급되었다.

    시스템 계층에서의 위치 (ISA-95)¶

    flowchart TB
    L4["Level 4 · 경영계획<br/>ERP, SCM (일·주·월 단위)"]
    L3["Level 3 · 제조운영<br/>MES / MOM (교대·시간·분 단위)"]
    L2["Level 2 · 감시·제어<br/>SCADA, HMI (초·분 단위)"]
    L1["Level 1 · 기기 제어<br/>PLC, 센서, 구동기 (밀리초 단위)"]
    L0["Level 0 · 생산 공정"]
    L4 <-->|"생산계획 ↓ / 실적 ↑"| L3
    L3 <-->|"작업 지시 ↓ / 현장 데이터 ↑"| L2
    L2 <--> L1
    L1 <--> L0

    MES는 ERP의 계획을 현장 실행으로 연결하고, 현장 실적을 ERP로 올려 보내는 다리 역할을 한다.

    MES의 주요 기능 (MESA-11)¶

    기능 내용
    자원 할당·상태 관리 설비·인력·자재·공구의 상태와 가용성 관리
    세부 일정계획 작업 순서·설비 배정 등 현장 단위의 일정 수립
    작업 지시(디스패칭) 일정에 따라 작업을 지시하고 변경 사항 반영
    문서 관리 작업표준서·도면·레시피 등 현장 문서 배포·관리
    데이터 수집 설비·작업자·검사 데이터의 실시간 수집
    인력 관리 작업자 투입·근태·숙련도 관리
    품질 관리 공정 검사, SPC, 불량 분석
    공정 관리 공정 조건 감시, 이상 발생 시 조치
    보전 관리 설비 보전 계획과 이력 관리
    제품 추적·계보 로트·시리얼별 자재·공정·품질 이력 추적(Traceability)
    성과 분석 생산량·OEE·수율·리드타임 등 실적 분석

    ERP와 MES 비교¶

    구분 ERP MES
    목적 전사 자원의 계획·관리 현장 생산의 실행·통제
    관리 단위 일·주·월, 금액·수량 중심 실시간(분·초), 설비·공정·로트 중심
    주요 사용자 경영·관리 부서 생산·품질·설비 현장
    데이터 계획·거래 데이터 실적·공정·설비 데이터

    도입 효과¶

    생산 현황의 실시간 가시화, 리드타임과 재공재고 감소, 품질 향상과 불량 원인 추적, 서류 작업 감소, 설비 가동률(OEE) 향상, 계획 대비 실적의 정확한 피드백, 스마트공장의 기반 시스템

    POP와 MES¶

    구분 POP(생산시점관리) MES
    초점 현장 실적 데이터의 수집 수집 + 계획·지시·품질·추적·분석의 실행 관리
    범위 작업 실적·설비 가동·불량 수량 MESA-11 기능 전반, ERP·설비와 양방향 연동
    관계 MES의 데이터 수집 기능에 해당 POP를 포함하는 상위 시스템

    구축 성공 요인과 최근 동향¶

    • 성공 요인: 경영층 의지와 현장 참여, 기준정보(BOM·라우팅·표준시간) 정비, 업무 표준화 선행, 설비 연동(PLC·OPC-UA) 계획, 단계적 구축과 KPI(OEE·리드타임·불량률)로 효과 검증
    • 최근 동향: 클라우드·SaaS MES(중소기업 보급), AI 기반 품질 예측과 디스패칭, 디지털 트윈 연계, 엣지 컴퓨팅, 탄소 배출 데이터 수집(ESG 대응)
    • 국내 스마트공장 수준 확인 체계에서 MES 구축 여부는 기초 단계 이상의 핵심 요소로 다뤄진다(세부 수준 기준은 교재 확인 필요) → 7.1.2
    • 연관 주제: ERP 7.1.1, APS 7.1.6, SCADA 4.5.3, OEE 3.5.3

    답안 작성 포인트

    • 10점 단답형은 정의 → ISA-95 계층 그림(ERP–MES–제어) → 주요 기능 5~6개 → 도입 효과로 쓴다.
    • "계획(ERP)과 실행(현장)의 단절을 메우는 시스템"이라는 핵심 메시지를 첫 문장에 둔다.
    • 마지막 줄에 "스마트공장의 핵심 플랫폼으로 AI·디지털 트윈과 연계되는 추세"를 한 줄 덧붙이면 차별화된다.
    관련 기출 2문항 (88회, 136회)
    • 제88회(2009) 1교시 1번 · 10점
      MES(Manufacturing Execution System)에 대해서 설명하시오.
    • 제136회(2025) 1교시 1번 · 10점
      제조실행시스템(MES, Manufacturing Execution System)에 대하여 설명하시오.

    2.5.2 MOM과 현장 데이터 수집¶

    MES와 MOM (127회)¶

    MOM(Manufacturing Operations Management, 제조운영관리)은 ISA-95 표준(Part 3)에서 정의한 개념으로, Level 3의 제조 운영 활동 전체를 포괄한다. MES가 주로 생산 실행에 초점을 둔다면, MOM은 생산·품질·보전·재고(물류) 운영을 모두 아우르는 상위 개념이다.

    구분 MES MOM
    범위 생산 실행 중심(작업 지시·실적·추적) 생산 + 품질 + 보전 + 재고 운영의 통합
    관점 개별 공장·라인의 시스템 여러 공장의 운영을 표준화·통합하는 관리 체계
    근거 MESA 기능 모델 ISA-95 Part 3 활동 모델
    관계 MOM의 핵심 구성 요소 MES를 포함하는 확장 개념

    MOM의 4대 운영 영역: ① 생산 운영 ② 품질 운영 ③ 보전 운영 ④ 재고(물류) 운영 — 각 영역마다 정의·자원·상세 일정·디스패칭·실행·데이터 수집·추적·분석 활동을 수행한다.

    스마트 데이터 수집 방법 (124회)¶

    방법 개념 특징
    Real-Time Management (실시간 관리) 현장 데이터를 발생과 동시에 수집·분석해 즉시 의사결정과 조치에 활용 지연 없는 현황 가시성, 이상의 즉시 감지·대응, 데이터 기반 의사결정, 일정 재수립의 신속성
    On-Line System (온라인 시스템) 설비·센서·단말기가 네트워크로 서버와 상시 연결되어 데이터가 자동으로 전송·처리되는 체계(일괄 입력 방식과 대비) 자동 수집으로 입력 누락·오류 감소, 시스템 간 연동(ERP·MES·SCADA), 원격 모니터링
    Paperless (종이 없는 현장) 작업 지시서·체크시트·작업 일보·검사 기록을 전자화(태블릿·키오스크·전자 작업표준서) 데이터 정확성과 검색성, 실시간 공유, 문서 관리 비용 감소, 이력 추적(Traceability) 용이

    현장 데이터 수집 수단: PLC·OPC-UA를 통한 설비 데이터 연동, IoT 센서, 바코드·RFID, 생산시점관리(POP) 단말기, 머신 비전

    flowchart LR
    S["설비·센서<br/>PLC, IoT, 비전"] --> E["엣지 게이트웨이<br/>수집·전처리"]
    W["작업자 단말<br/>태블릿·바코드·RFID"] --> E
    E --> M["MES / MOM<br/>실시간 모니터링·분석"]
    M <--> R["ERP·SCM"]
    M --> D["대시보드·알람<br/>즉시 조치"]
    데이터 수집 방식 수작업 입력(일괄) 자동 수집(온라인·실시간)
    시점 작업 종료 후 일괄 입력 발생 즉시
    정확도 누락·오기 발생 높음
    활용 사후 집계·보고 실시간 이상 감지, 추적, AI 분석

    도입 시 유의점: 데이터 표준(코드·단위)과 통신 표준(OPC-UA, ISA-95 기반 인터페이스) 정의, 수집 목적(KPI)부터 정하고 필요한 데이터만 수집, 사이버보안, 작업자 교육과 현장 수용성 확보

    답안 작성 포인트

    • MES와 MOM은 포함 관계(MOM ⊃ MES)와 ISA-95 근거를 분명히 쓰고, 비교표로 정리한다.
    • 124회처럼 세 가지 개념을 물으면 각각 개념 + 특징 3개 + 기대효과를 같은 형식으로 반복해 쓴다.
    • 연관 주제: IoT·센서 네트워크 7.1.3, 스마트공장 7.1.2
    • 결론 예: "세 방법은 Paperless로 데이터를 전자화하고, On-Line으로 자동 연결하며, Real-Time으로 즉시 활용하는 단계적 관계이며, 데이터 표준화와 보안을 전제로 AI 분석·디지털 트윈으로 확장해야 한다."
    관련 기출 2문항 (124회, 127회)

      2) On-Line System
      3) Paperless

    • 제127회(2022) 1교시 9번 · 10점
      MES(Manufacturing Execution System)와 MOM(Manufacturing Operation Management)

    답안 작성 예시¶

    25점 예시: 제124회 4교시 6번 — 스마트 데이터 수집 방법(Real-Time Management, On-Line System, Paperless)의 개념과 특징

    1. 개요

    • 스마트공장은 현장 데이터의 수집 → 분석 → 조치의 순환으로 운영되며, 데이터 수집 방식이 MES·MOM 성과를 좌우한다.
    • [그림] 설비·작업자 → 엣지 → MES → ERP / 대시보드의 수집 구조도

    2. 본론

    • (1) Real-Time Management: 개념(발생 즉시 수집·분석·조치) + 특징 3개(즉시 가시성, 이상 즉시 대응, 신속 재일정) + 기대효과
    • (2) On-Line System: 개념(설비·단말의 상시 네트워크 연결, 일괄 입력과 대비) + 특징 3개(자동 수집, 시스템 연동, 원격 감시) + 기대효과
    • (3) Paperless: 개념(지시서·체크시트·일보 전자화) + 특징 3개(정확·검색성, 실시간 공유, 추적성) + 기대효과
    • (4) [표] 수작업 일괄 입력 vs 자동·실시간 수집 비교, 수집 수단(PLC·OPC-UA·IoT·RFID·비전)
    • (5) 세 방법의 관계: Paperless(전자화) → On-Line(연결) → Real-Time(활용)

    3. 결론(기술사 의견)

    • 데이터 표준·보안·현장 수용성이 전제이며, 수집 데이터를 OEE·품질 KPI로 연결해야 효과가 난다.
    • 차별화: AI 품질 예측·디지털 트윈으로의 확장 로드맵과 ESG(에너지·탄소) 데이터 수집까지 언급

    10점 예시: 제136회 1교시 1번 — 제조실행시스템(MES)

    • 개요: ERP의 계획과 현장 설비·작업자 사이에서 작업 지시부터 완제품까지 생산 활동을 실시간 관리·통제하는 현장 정보시스템(MESA 정의 인용)
    • 핵심 내용 ①: [그림] ISA-95 계층(Level 4 ERP – Level 3 MES – Level 2 SCADA – Level 1 PLC)
    • 핵심 내용 ②: 주요 기능 5~6개(작업 지시, 데이터 수집, 품질, 추적·계보, 성과 분석, 보전) — MESA-11에서 선택
    • 핵심 내용 ③: ERP와의 비교 한 줄(계획·월 단위 vs 실행·실시간)
    • 활용/의견: 리드타임·재공 감소, OEE 향상, 추적성 확보 → 스마트공장의 핵심 플랫폼으로 AI·디지털 트윈과 연계되는 추세
