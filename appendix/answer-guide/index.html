    답안 작성 가이드¶

    기술사 필기는 아는 것을 채점자가 읽기 쉽게, 정해진 시간 안에, 기술사다운 관점으로 써내는 시험이다. 이 교재의 각 세부항목 페이지는 이 가이드의 틀(개요 → 본론 → 결론)에 맞춰 내용을 정리했고, 페이지 끝의 답안 작성 예시로 연습할 수 있다.

    1. 시험 구조와 시간 배분¶

    교시 형식 문항 배점 문항당 시간(권장) 분량(권장)
    1교시 단답형 13문항 중 10문항 선택 각 10점 약 9분 약 1페이지
    2·3·4교시 논술형 6문항 중 4문항 선택 각 25점 약 23분 약 3페이지

    (교시당 100분. 처음 3~5분은 문제 선택·구상에, 마지막 3~5분은 검토에 쓴다.)

    문제 선택 요령

    1. 전체 문제를 먼저 읽고 확실히 쓸 수 있는 문제 → 계산 문제 → 부분적으로 아는 문제 순으로 고른다.
    2. 계산 문제는 풀이 과정이 명확하면 점수가 안정적이므로 적극 선택한다.
    3. 선택한 문제마다 여백에 키워드·도해·표 구성을 30초~1분 안에 먼저 적는다.

    2. 답안의 기본 틀¶

    10점 단답형¶

    1. 정의(개요)      : 1~2줄 — 누가·언제·무엇을 위해 제시했는지
2. 핵심 내용       : 구성 요소·종류·절차를 표 또는 그림 1개로
3. 특징·효과(활용) : 3~4개 항목
4. 의견(활용 방향) : 1~2줄 — 실무 적용·최신 동향

    25점 논술형¶

    1. 개요
   - 정의, 등장 배경, 필요성(왜 중요한가) — 3~5줄
2. 본론 (문제의 소문항 번호를 그대로 소제목으로)
   (1) 개념·원리 — 도해 1개
   (2) 종류·비교 — 비교표 1개
   (3) 절차·방법 — 흐름도 또는 단계표
   (4) 사례·계산 — 공장 사례, 수치 예
3. 결론(기술사 의견)
   - 현장의 문제점과 개선 방향, 최신 동향(스마트공장·AI·ESG)과의 연결 — 3~5줄

    3. 계산 문제 작성법¶

    ① 주어진 조건 정리(기호와 단위)
② 사용 공식(기호 설명 포함)
③ 대입과 계산(중간 과정을 생략하지 않음)
④ 결과(단위, 소수점 조건 준수)
⑤ 판정(기준과 비교: 채택/기각, 적합/부적합)
⑥ 해석과 개선 의견(결과가 의미하는 것, 조치 방안)
    • 문제의 조건이 부족하면 가정을 명시하고 푼다(예: "현재일을 0으로 가정").
    • 여러 대안을 비교할 때는 결과를 한 표에 모아 판정한다.

    4. 고득점 포인트¶

    포인트 방법
    구조화 번호 체계(1. → (1) → ①)와 소제목으로 채점자가 한눈에 찾게 함
    도해 25점 문항에는 그림·표를 최소 2개(구조도·비교표·흐름도·그래프)
    소문항 대응 문제의 질문 하나하나에 빠짐없이 대응, 질문의 순서와 용어를 그대로 사용
    핵심어 강조 학자명·이론명·공식·수치를 정확히 쓰고 밑줄로 강조
    실무성 공장 사례, 정량 효과(예: 리드타임 30% 단축) 제시
    최신성 스마트공장·AI·디지털 트윈·ESG·공급망 리스크와 연결
    연계성 관련 이론과 연결(예: OEE ↔ TPM ↔ SMED, BEP ↔ 원가 전략)

    5. 감점 요인¶

    • 질문과 다른 내용을 길게 서술(질문 회피)
    • 소문항 일부 누락, 결론 없음
    • 정의·공식·학자명의 오류
    • 그림·표 없이 긴 줄글만 작성
    • 계산에서 단위·소수점 조건 누락, 판정 없이 숫자만 제시
    • 시간 배분 실패로 마지막 문항 미완성

    6. 결론 문장 패턴¶

    유형 문장 예
    개선 방향 "○○는 △△의 한계가 있으므로, □□와 연계해 단계적으로 추진해야 한다."
    최신 동향 "최근 스마트공장·AI의 확산으로 ○○는 실시간 데이터 기반의 △△로 발전하고 있다."
    실무 적용 "현장에서는 ○○를 먼저 안정화한 후 △△를 적용하는 것이 효과적이다."
    경영 관점 "○○는 원가·품질·납기의 경쟁우위를 확보하는 핵심 수단으로, 경영층의 의지와 전원 참여가 성공의 관건이다."
    균형 관점 "○○와 △△는 상충관계이므로, 총비용 관점에서 최적점을 찾아야 한다."

    7. 학습 우선순위¶

    1. 반복 출제 주제부터 — 출제 빈도 분석의 상위 세부항목·주제(품질관리, 설비보전, 생산구조·배치, 제품개발, OR, 작업측정)
    2. 계산 유형 숙달 — 예측오차·EOQ·MRP·라인밸런싱·OEE·신뢰도·BEP·NPV·LP·PERT
    3. 최근 5개 회차의 새 주제 — 디지털 전환·AI·ESG 통상규제·미래 공장(7.1, 7.5)
    4. 새 출제기준의 신규 영역 — 4.4 시설 및 유틸리티관리
    5. 각 페이지 끝의 답안 작성 예시로 실제 답안지에 시간을 재며 써 보기
